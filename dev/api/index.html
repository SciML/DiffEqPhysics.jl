API

The following functions and types make up the public API of DiffEqPhysics.jl.

Problem Types

DiffEqPhysics.HamiltonianProblem — Type
HamiltonianProblem(H, p0, q0, tspan, param=nothing; kwargs...)
HamiltonianProblem((dp, dq), p0, q0, tspan, param=nothing; kwargs...)

Define a physical system by its Hamiltonian function H(p, q, param, t) or the function pair dp = -∂H/∂q and dq = ∂H/∂p.

The equations of motion are then given by q̇ = ∂H/∂p = dq and ṗ = -∂H/∂q = dp.

The initial values for canonical momenta p0 and coordinates q0 may be scalars, SArrays, or other AbstractArrays. Their type determines whether the problem uses in-place or out-of-place operations.

  • For scalars and SArrays, the derivative functions use the signatures dp(p, q, param, t) and dq(p, q, param, t).
  • For regular AbstractArrays, the partial derivatives use mutating signatures dp!(Δp, p, q, param, t) and dq!(Δq, p, q, param, t) with preallocated arrays Δp and Δq.

If the Hamiltonian function is given, dp and dq are calculated automatically using automatic differentiation (ForwardDiff.jl).

Note

H should be defined as H(p, q, param, t). For backward compatibility, H(p, q, param) is also supported but deprecated.

Plotting

DiffEqPhysics.plot_orbits — Function
plot_orbits(sol; body_names=nothing, dim=3, kwargs...)

Plot the orbits from an N-body simulation solution.

Arguments

  • sol: A solution from solving an N-body problem
  • body_names: Optional vector of names for each body (defaults to "orbit 1", "orbit 2", etc.)
  • dim: Dimension of the plot, either 2 or 3 (default: 3)
  • kwargs...: Additional keyword arguments passed to plot

Returns

A plot object showing the trajectories of all bodies.

See also: orbitplot

DiffEqPhysics.orbitplot — Function
orbitplot(sol; body_names=nothing, dim=3, kwargs...)

Plot the orbits from an N-body simulation solution using Plots.jl recipes.

Arguments

  • sol: A SciML solution from solving an N-body problem
  • body_names: Optional vector of names for each body (defaults to "orbit 1", "orbit 2", etc.)
  • dim: Dimension of the plot, either 2 or 3 (default: 3)
  • kwargs...: Additional keyword arguments passed to the plot recipe

Returns

A plot object showing the trajectories of all bodies.
